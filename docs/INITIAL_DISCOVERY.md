## Initial baseline

The three `config/<ID>/config.yml` files use the verified DOL paths and hashes.
`ninja -j2` completed for each version, and all three linked `main.dol` files
passed their SHA-1 checks. The autogenerated configurations contain 73, 73,
and 70 assembly units for GPXE01, GPXP01, and GPXJ01 respectively. The
`splits.txt` files currently identify sections only. `symbols.txt` began as
decomp-toolkit's initial analysis output and now includes 90 shared SDK names
verified across Box's three regions, XD, and Colosseum; see
`docs/SYMBOL_RECOVERY.md`. Original source-file boundaries,
compiler versions, and matching source objects remain unknown. The next split
work must be grounded in map, symbol, or object evidence rather than inferred
from the successful relink alone.
